プライバシーポリシー（日本語）

最終更新日: 2026年11月26日 / 提供者: MahorobaLab

MetaCSV（デスクトップアプリ版、VS Code / Open VSX 拡張機能版、および Web / PWA 版を含みます）は、 ユーザーのプライバシーとデータ安全性を最優先に設計された完全ローカル動作の CSV エディタ／ビューアです。

1. データの収集・送信について

  • 本アプリケーションは、CSV ファイル本体・.meta.jsonc ファイルの内容・検索履歴・利用統計などの個人データや業務データを外部サーバーへ送信・収集しません。
  • アクセス解析、広告 SDK、トラッキングツール、テレメトリー送信機能は一切含まれていません。

2. 端末内に保存される設定情報

  • デスクトップアプリ版: テーマ設定、ウィンドウの位置・サイズ、最後に開いたディレクトリのパスなどのアプリ設定のみを、OS 標準のローカル設定フォルダ内に保存します。
  • Web / PWA 版: テーマ設定、検索／フィルタ入力履歴などの利便性設定を、お使いのブラウザ内の localStorage およびオフラインキャッシュに保存します。外部へ送信されることはありません。
  • VS Code / Open VSX 拡張機能版: エディタの動作に必要なローカルファイルのみを IDE 内で直接読み書きします。

3. 外部リンクについて

本サイトまたはアプリ内のヘルプ等には GitHub リポジトリや各ストアへの外部リンクが含まれる場合があります。リンク先における情報の取り扱いは各サービスのプライバシーポリシーに従います。

4. お問い合わせ

本プライバシーポリシーに関するお問い合わせは、 GitHub Issues (mahorobalab/meta-csv) までご連絡ください。

Privacy Policy (English)

Last updated: November 26, 2026 / Developer: MahorobaLab

MetaCSV (including the Desktop app for Windows/macOS, the VS Code / Open VSX extension, and the Web / PWA edition) is a local-first CSV editor and viewer designed with privacy by default.

1. Data Collection and Transmission

  • MetaCSV does not collect, transmit, or upload your CSV files, .meta.jsonc sidecar files, search queries, or usage metrics to any external server.
  • No analytics, telemetry, crash-reporting trackers, or advertising SDKs are included.

2. Local-Only Storage

  • Desktop App: Stores only local UI preferences (theme mode, window position/size, and last opened directory) inside your OS application configuration directory.
  • Web / PWA Edition: Stores UI preferences and search/filter history locally in your browser's localStorage and offline Service Worker cache. Nothing leaves your device.
  • VS Code / Open VSX Extension: Reads and writes only the workspace/local files you explicitly open in your IDE.

3. External Links

Links to GitHub, Microsoft Store, BOOTH, or extension marketplaces lead to third-party services governed by their respective privacy policies.

4. Contact

If you have any questions about this Privacy Policy, please open an issue at GitHub Issues (mahorobalab/meta-csv) .
