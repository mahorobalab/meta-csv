Key Capabilities

Designed for developers, data analysts, and log inspection workflows.

.metatext.jsonc Sidecar

Zero-config auto-fit on first open. Column widths, frozen panes, 5-layer Excel-like styles, and sort order are persisted in *.csv.metatext.jsonc.

Comment-Preserving JSONC

Powered by Microsoft's jsonc-parser: GUI edits patch metadata cleanly while preserving your handwritten comments and formatting.

Log-Analysis Filter Bar

Supports OR, -exclude, col:val, numeric comparisons, /regex/, grep -C context rows, consecutive dedupe, and frequency facets.

100% Local & Privacy-First

Zero servers, zero telemetry. Even the Web / PWA version parses and edits CSV files completely inside your browser via Web Workers.

Platforms & Distribution

Open-source core on GitHub (MIT); official signed desktop builds distributed via Microsoft Store & BOOTH (no binaries on GitHub Releases).
