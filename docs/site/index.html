Architecture

              
Built for real-world data & log workflows.

              

                No silent date reformatting, no dropped leading zeros, no bloated binary lock-in.
              

            

          


          

            

              01 / SIDECAR METADATA
              
Comment-preserving .metatext.jsonc

              

                5-layer styling (table, columns, conditional rules, ranges, cells), column widths,
                frozen panes, and non-destructive sort order are patched via Microsoft's
                jsonc-parser — your handwritten comments stay intact.
              

              

                table → columns → rules → ranges → rows / cells
              

            


            

              02 / QUERY & LOG ANALYSIS
              
Log-grade filter bar & Live Tail

              

                Query with col:val, OR,
                -exclude, numeric comparisons, and
                /regex/. Includes grep -C
                context rows, duplicate collapse, value facets, presets, and real-time Live Tail.
              

              

                level:ERROR -service:health /timeout/i  |  ±3 context  |  Live Tail
              

            


            

              03 / 2-LAYER HISTORY
              
Undo/Redo + Shadow Git

              

                Instant in-memory undo/redo paired with persistent save snapshots stored in a
                local .metatext.history/ Git repository. Restore any snapshot byte-for-byte.
              

            


            

              04 / PORTABLE BUNDLE
              
.metatext.zip archive

              

                Bundle raw data, .metatext.jsonc styling, and
                optional history into one portable archive. Open and edit directly across Desktop,
                VS Code, and Web.
              

            


            

              05 / FORMATS & PRIVACY
              
Multi-format, 100% local

              

                Preserves UTF-8, UTF-8 BOM, Shift-JIS, LF/CRLF, and delimiters. Zero servers, zero
                telemetry — even the Web edition runs entirely in local Web Workers.
