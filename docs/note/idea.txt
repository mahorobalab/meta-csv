# Meta CSV 

Web, Windows, Mac, VS Code で動く
Tauriで実装

## メタデータに持つもの

列幅
行の高さ
フォント
太字、イタリック
セル背景色
ソート順の記憶
検索

・CSV エディタ、ビューアでメタデータと連動する

・ほぼ同じ仕組みで、MetaLogが作れそう
  → MetaLogは、読み取り専用
  → フィルター、検索、マーカーは実装
  → 保存したい場合は、ロック解除してから

・~.csv.meta.jsonc じゃなくて、~.*.metatext.jsonc に拡張
log やcsv 含めたJSON Schema定義する。

・履歴管理は、gix
