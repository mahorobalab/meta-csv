MetaText Editor

【短い説明 / Short Description】（100文字以内・検索結果カードに表示）

【説明 / Description】（10,000文字以内）
MetaText Editor は、大規模な CSV や構造化テキストを軽快に閲覧・編集できる高速 CSV エディタ＆ビューアです。

10万行を超える CSV / TSV / JSONL (NDJSON) / ログファイルを 60fps の滑らかな表計算風グリッドで開きながら、元のデータファイル自体は一切汚さず Git フレンドリーな状態を保ちます。

列幅・セルや行の色付け・条件付き書式・表示ソート順・行マーカー・フィルタプリセットなどの見た目の情報は、データ本体には書き込まず、隣の `.metatext.jsonc` サイドカーファイルに自動保存します。

■ CSV 編集に MetaText Editor が選ばれる理由
- 10万行以上の大きな CSV でもフリーズせず軽快にスクロール・検索・フィルタ。
- UTF-8 / UTF-8 BOM / Shift-JIS、改行コード（LF / CRLF）、区切り文字を自動判別してそのまま保持。Excel のような勝手な日付変換や先頭ゼロ落ちが起きません。
- 装飾は `.metatext.jsonc` に分離されるため、Git の差分も常にクリーンです。

■ 強力な検索・フィルタ・集計機能
- クエリフィルタ（`col:val`, `OR`, `-not`, `>100`, `/regex/`）、前後行表示（`grep -C`）、連続重複の折りたたみ、列の集計（ファセット）、フィルタプリセット保存に対応。
- 非破壊ビューソート：元ファイルの行順を変えずに、表示上だけ瞬時に並び替え。
- 5 色の行マーカー＆メモ機能と、マーカー間の高速ジャンプ。
- ログや JSONL の追記をリアルタイム追跡できる Live Tail モードを搭載。

■ 2 層履歴と `.metatext.zip` ポータブル共有
- 2 層履歴システム：メモリ内の即時 Undo/Redo に加え、保存ごとのスナップショットを軽量なローカル Shadow Git（`.metatext.history/`）に記録し、過去の任意の時点へ安全に復元可能。
- ポータブルバンドル（`.metatext.zip`）：CSV 本体・`.metatext.jsonc` 装飾・任意の履歴を 1 つの ZIP にまとめて共有でき、MetaText Editor でそのまま開いて編集できます。

■ 対応フォーマット
- CSV（`.csv`）
- TSV（`.tsv`）
- JSONL / NDJSON（`.jsonl`, `.ndjson`・ネスト自動展開対応）
- ログファイル（`.log`・IIS W3C / Docker・JSON ログ / カスタム正規表現プリセット対応）
- MetaText ポータブルバンドル（`.metatext.zip`）
