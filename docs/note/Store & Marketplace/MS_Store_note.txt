[Description] (Max 10,000 chars)
MetaText Editor is a high-performance CSV editor and viewer built for developers, analysts, and anyone working with large structured text files.

Open and edit 100,000+ rows smoothly at 60fps in a spreadsheet-like Canvas grid — while keeping your raw CSV, TSV, JSONL/NDJSON, and log files 100% clean and Git-friendly.

Instead of modifying or converting your original CSV file, MetaText Editor saves all visual metadata — column widths, cell/row colors, conditional formatting rules, view sort order, row markers, and filter presets — in a companion `.metatext.jsonc` sidecar file next to your data.

■ Why MetaText Editor for CSV & Structured Text?
- Opens huge CSV files (100k+ rows) smoothly without freezing like traditional spreadsheet apps.
- Preserves your original encoding (UTF-8, UTF-8 BOM, Shift-JIS), line endings (LF/CRLF), and delimiters — no unwanted date auto-conversion or broken leading zeros.
- Keeps diffs clean in Git because formatting lives in `.metatext.jsonc` with comments preserved.

■ Powerful Data Exploration
- Instant query filtering (`col:val`, `OR`, `-not`, `>100`, `/regex/`), context rows (`grep -C`), consecutive duplicate collapse, column value facets, and reusable filter presets.
- Non-destructive view sorting: sort any column without changing the underlying row order.
- Row markers with 5 colors and notes, plus quick jump navigation.
- Live Tail mode for real-time monitoring of growing `.log` and `.jsonl` files.

■ Built-in History & Portable Sharing
- 2-Layer History: instant in-memory Undo/Redo plus persistent save snapshots stored in a lightweight local Shadow Git repository (`.metatext.history/`).
- Portable Bundles (`.metatext.zip`): package your CSV/JSONL/LOG file, `.metatext.jsonc` styling, and optional snapshot history into a single portable archive that opens directly in MetaText Editor.

■ Supported Formats
- CSV (`.csv`)
- TSV (`.tsv`)
- JSONL / NDJSON (`.jsonl`, `.ndjson`) with automatic key flattening
- Log files (`.log`) with IIS W3C, Docker/JSON, and custom regex parser presets
- MetaText Portable Bundle (`.metatext.zip`)
