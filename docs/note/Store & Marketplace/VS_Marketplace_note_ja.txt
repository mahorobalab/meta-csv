# MetaText Editor

`.metatext.jsonc` サイドカーメタデータで強化された、VS Code 向けの高速 CSV / TSV / JSONL (NDJSON) / ログ エディタ＆ビューアです。

元のデータファイルを一切汚さず Git フレンドリーな状態を保ったまま、列幅・セル/行スタイル・条件付き書式・表示ソート順・行マーカー・フィルタプリセットなどを隣の `<ファイル名>.metatext.jsonc` に保存します。

## 主な機能

- **10万行以上を 60fps で快適表示**: 大規模な CSV / TSV / JSONL / ログ向けに設計された高速 Canvas グリッド。
- **元ファイルを汚さない `.metatext.jsonc` サイドカー**: 生データと装飾を完全分離。編集時も JSONC のコメントや書式を保持し、JSON Schema による補完・検証にも対応。
- **リッチな装飾機能**: 5 層スタイルカスケード（テーブル・列・条件付きルール・範囲・行/セル）、ゼブラ行、数値書式、折り返し表示、メモ付き行マーカー。
- **強力なフィルタ＆集計**: クエリ検索（`col:val`, `OR`, `-not`, `>100`, `/regex/`）、前後行表示（`grep -C`）、連続重複の折りたたみ、列の集計（ファセット）、プリセット保存。
- **非破壊ビューソート**: 元ファイルの行順を変えずに、表示上だけ高速ソート。
- **Live Tail モード**: ログや JSONL ファイルの追記をリアルタイム追跡。
- **2 層履歴（Undo/Redo + Shadow Git スナップショット）**: メモリ内の即時 Undo/Redo に加え、保存ごとのスナップショットを軽量なローカル Shadow Git（`.metatext.history/`）に記録・復元可能。
- **ポータブルバンドル（`.metatext.zip`）**: データ・メタデータ・任意の履歴を 1 ファイルにまとめて直接編集・エクスポート可能。
- **文字コード・改行・区切り文字の保持**: UTF-8 / UTF-8 BOM / Shift-JIS、LF / CRLF、区切り文字を自動判別して保存時に維持。
- **8 言語対応**: 日本語・英語・簡体字中国語・繁体字中国語・韓国語・ドイツ語・フランス語・スペイン語。

## 対応フォーマット

- `.csv`（CSV）
- `.tsv`（TSV）
- `.jsonl` / `.ndjson`（JSON Lines・ネスト自動展開対応）
- `.log`（IIS W3C・Docker/JSON ログ・カスタム正規表現プリセット対応）
- `.metatext.zip`（ポータブル MetaText バンドル・既定エディタ）

5. パッケージ作成＆公開チェックリスト
----------------------------------------------------------------------
1. `apps/vscode/` に以下を配置する:
   - `README.md`（Marketplace ページの Overview 本文。英語推奨）
   - `CHANGELOG.md`（Changelog タブ用）
   - `LICENSE`（MIT ライセンス本文）
   - `media/icon.png`（128x128 以上の PNG）
2. `apps/vscode/package.json` に `icon`, `keywords`, `categories`, `galleryBanner`, `bugs` を追記。
3. 拡張機能と Webview をビルド:
   pnpm.cmd --filter metatext-editor build
4. VSIX ファイルを作成:
   npx @vscode/vsce package
5. 以下の管理画面から生成された `metatext-editor-1.0.0.vsix` をアップロード:
   https://marketplace.visualstudio.com/manage/publishers/mahorobalab
   （「+ New extension」→「Visual Studio Code」）
   ※CLI から公開する場合は `npx @vscode/vsce publish`
