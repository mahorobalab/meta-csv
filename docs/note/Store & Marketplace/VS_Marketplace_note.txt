3. Overview / README.md Draft (Displayed on Marketplace Page)
----------------------------------------------------------------------
# MetaText Editor

High-performance CSV, TSV, JSONL/NDJSON & Log editor and viewer for VS Code — powered by `.metatext.jsonc` sidecar metadata.

Keep your raw data files clean and Git-friendly while saving column widths, cell/row styles, conditional formatting, sort order, row markers, and filter presets in an adjacent `<filename>.metatext.jsonc` file.

## Key Features

- **100k+ Rows at 60fps**: Smooth Canvas-based data grid built for large CSV, TSV, JSONL/NDJSON, and log files.
- **Clean, Git-Friendly Sidecar (`.metatext.jsonc`)**: Never pollutes your raw CSV/JSONL/LOG files. Comments and formatting in `.metatext.jsonc` are preserved on every edit, with built-in JSON Schema validation & autocompletion.
- **Rich Visual Styling**: 5-layer style cascade (table, columns, conditional rules, ranges, rows/cells), zebra striping, number formatting, text wrapping, and row markers with notes.
- **Powerful Filtering & Facets**: Instant query filtering (`col:val`, `OR`, `-not`, `>100`, `/regex/`), context rows (`grep -C`), consecutive duplicate collapse, column value facets, and reusable filter presets.
- **Non-Destructive View Sort**: Sort any column in the view without mutating the underlying file order.
- **Live Tail Mode**: Follow appended lines in real time for log and JSONL files.
- **2-Layer History (Undo/Redo + Shadow Git Snapshots)**: Instant in-memory undo/redo plus persistent save snapshots stored in a lightweight local Shadow Git repository (`.metatext.history/`).
- **Portable Bundles (`.metatext.zip`)**: Open, edit, and export self-contained `.metatext.zip` archives bundling data, metadata, and optional snapshot history.
- **Encoding & Dialect Preservation**: Automatically detects and preserves UTF-8, UTF-8 BOM, Shift-JIS, LF/CRLF, and delimiters.
- **8 Languages**: English, Japanese, Simplified Chinese, Traditional Chinese, Korean, German, French, and Spanish.

## Supported Formats

- `.csv` (Comma-Separated Values)
- `.tsv` (Tab-Separated Values)
- `.jsonl` / `.ndjson` (JSON Lines with automatic key flattening)
- `.log` (IIS W3C, Docker/JSON logs, and custom regex presets)
- `.metatext.zip` (Portable MetaText Bundle — default editor)

5. Packaging & Publishing Quick Checklist
----------------------------------------------------------------------
1. Add `apps/vscode/README.md`, `apps/vscode/CHANGELOG.md`, `apps/vscode/LICENSE`,
   and `apps/vscode/media/icon.png` (128x128+ PNG).
2. Remove `"private": true` (or keep it if publishing manually; vsce accepts it
   with warning, or omit `"private"` in apps/vscode/package.json).
3. Build extension & webview:
   pnpm.cmd --filter metatext-editor build
4. Package VSIX:
   npx @vscode/vsce package
5. Upload the generated `metatext-editor-1.0.0.vsix` at:
   https://marketplace.visualstudio.com/manage/publishers/mahorobalab
   ("+ New extension" -> "Visual Studio Code")
   OR publish via CLI:
   npx @vscode/vsce publish
